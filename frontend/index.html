Quantitative Engine Architecture Reference

What is Phase 1 Signal and where does it come from?

The Phase 1 Signal is GenWealth's core mathematical directional probability score (from 0.0000 to 1.0000). It quantifies the statistical likelihood that an equity asset will generate positive forward excess returns. It is derived from a 3-pillar institutional ensemble:

Exact Ensemble Formulation:
Phase 1 Signal = (0.45 × LSTM_Prob) + (0.45 × RF_Prob) + (0.10 × Sentiment_Score)
🧠
PyTorch LSTM (45% Weight)

Processes a 60-day historical window of 23 quantitative indicators (RSI, MACD, Bollinger Bands, ATR, Stochastics, EMAs). Captures non-linear temporal sequence patterns and momentum velocity.

🌲
Random Forest (45% Weight)

100-estimator decision tree ensemble evaluating cross-sectional feature interactions, volume divergence, volatility regimes, and multi-factor valuation metrics to classify directional probability.

📰
FinBERT NLP (10% Weight)

Scrapes real-time global news headlines and financial disclosures, running transformer-based sentiment analysis to convert qualitative sentiment polarity into a normalized score [0, 1].

Institutional Decision Thresholds:

  • BULLISH (> 0.65): High conviction upward trend acceleration. Momentum, tree consensus, and news sentiment align positively.
  • NEUTRAL / HOLD (0.35 – 0.65): Consolidation or conflicting indicators. Suggests maintaining risk hedges or watching for breakout.
  • BEARISH (< 0.35): Downside momentum, technical deterioration, or adverse news sentiment. Capital preservation advised.

What is the difference between Live Engine Open and Close?

The Live Engine toggle gives you control over whether the platform executes live computational inference across global exchanges or relies on pre-computed benchmark cache snapshots:

LIVE ENGINE OPEN (ON / GREEN)

Real-Time Global Inference Mode

  • Universal Coverage: Evaluates any international stock ticker dynamically (e.g. PAYTM.NS, 7203.T, BABA, SHEL.L, NVDA).
  • Live Market Data: Fetches adjusted OHLCV bars directly from live exchange feeds.
  • Dynamic Feature Engineering: Computes all 23 quantitative indicators on the fly and feeds them into the PyTorch LSTM neural network and Scikit-Learn Random Forest in memory.
  • Live News & RAG: Scrapes current real-time financial news, runs FinBERT NLP sentiment, and populates live vector embeddings.
LIVE ENGINE CLOSED (OFF / GRAY)

Offline Benchmark Snapshot Mode

  • Pre-Computed Baseline: Uses pre-calculated static Phase 1 CSV datasets from training runs (e.g. core benchmark basket: RELIANCE.NS, TCS.NS, HDFCBANK.NS, NVDA).
  • Zero External Scraping: Does not make live web requests or real-time model re-inferences.
  • Fast Baseline Reproduction: Ideal for rapid offline regression testing, backtesting verification, and fixed baseline comparisons without API latencies.
